# Top Football Leagues Scorers - Data Cleaning Project

## 📌 Overview
This project focuses on cleaning and preparing data about top scorers in the major football leagues. The main goal was to ensure data quality and consistency by removing duplicates, correcting misspelled player names, and organizing the dataset to be ready for analysis and visualization.

## 📂 Dataset
- **Source**: [Kaggle - Top Football Leagues Scorers](https://www.kaggle.com/datasets/mohamedhanyyy/top-football-leagues-scorers)
- The dataset contains information on top scorers from various football leagues over several seasons.

## 🧹 Tasks Performed
- Removed duplicate entries.
- Standardized player names and corrected typos.
- Checked and unified team names.
- Ensured all records follow a consistent structure.
- Used SQL queries for data cleaning and validation.
- Additional inspection and corrections using Excel.

> **Note**: This project was part of a collaborative effort. Other team members handled data visualization based on the cleaned dataset.

## 🛠️ Tools Used
- **SQL**: For querying and cleaning the dataset.
- **Microsoft Excel**: For manual inspection and minor corrections.
